
# ConeyComb

## A C version and improvement of the HoneyComb esoteric programming language.

### What is ConeyComb

ConeyComb is a C implementation of the HoneyComb esoteric programming language, which is designed to be a fun and challenging way to explore programming concepts implemented with designs and structures from nature. HoneyComb uses a unique hexagonal grid structure for its memory model, which allows for interesting and complex interactions between cells.

### Features

- Hexagonal grid memory model
- Bytecode compiler and interpreter
- Support for standard HoneyComb operations
- Easy to use command-line interface
- Cross-platform compatibility

### Getting Started

To get started with ConeyComb, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/MOHAPY24/ConeyComb.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ConeyComb
   ```

3. Run the wrapper script to compile and execute a HoneyComb program:

   ```bash
   ./src/bin/hyc your_program.hc
   ```

### Example

Here is a simple example of a HoneyComb program that increments a cell value:

```hc
>+++++.
```

This program moves to the right cell, increments its value by 5, and then outputs the value.
